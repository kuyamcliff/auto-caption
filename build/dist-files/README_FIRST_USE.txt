AUTOCAPTION AE 1.0.0
====================

1. Double-click INSTALL_EXTENSION.bat.
2. Open (or restart) After Effects.
3. Open Window > Extensions > AutoCaption AE.
4. On first launch, choose the "backend" folder.
5. Wait for verification.
6. Select an audio, video, or precomp layer.
7. Click Transcribe.
8. Edit captions.
9. Choose words per line.
10. Choose an animation.
11. Click Create Text Layers.

Everything runs locally.
No Node.js installation is required.
No Python installation is required.
No FFmpeg installation is required.
No cloud transcription is required.
Your audio stays on this computer.

Requirements: Windows 10/11 x64, After Effects 2022 (22.0) or newer,
about 6 GB of free disk space and 8 GB of RAM (16 GB recommended for the
Small model on long files). An NVIDIA GPU is used automatically when
available; otherwise the CPU is used.

You can keep only the "extension" and "backend" folders. The backend
folder can live anywhere (for example C:\Tools\AutoCaptionAE\backend);
if you move it, open the panel's Settings > Backend > Locate Backend.

Trouble? Run VERIFY_INSTALLATION.bat, or open Settings > Diagnostics in
the panel and click "Copy diagnostics".
